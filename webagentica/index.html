Towards an agent-native web

The web was built to share pages.
What if it could share agents?

WebAgentica is a proposed open architecture for agents that anyone can create, publish, discover, download and run — with their own model, memory, tools and budget.

01 / THE IDEA

Unbundle the agentic web.

Today's agent platforms frequently combine the tool that creates an agent, the infrastructure that hosts it, and the compute that executes it. The Web took a different path: page builders, hosts and browsers evolved independently.

WebAgentica proposes the same separation for portable AI agents. A creator publishes a signed, versioned agent.pkg. A visitor's AgentSurfer retrieves the package, verifies its provenance, requests appropriate permissions and runs it with a chosen model and runtime. The publisher need not pay for every visitor's inference.

03 / WHY THIS IS DIFFERENT

Not just an agent that clicks websites.

Conventional agentic browsing automates existing human-facing pages. AgentSurfer would instead execute behavior deliberately published as an agent package. Browser automation can remain a tool, not the defining architecture.

AGENTIC BROWSER TODAY

Agent drives a webpage

Visiting AI→ clicks →Existing website

The visiting agent infers actions from rendered pages and interfaces.

WEBAGENTICA PROPOSAL

Browser runs an agent

Published agent.pkg→ executes →AgentSurfer

The publisher provides portable behavior; the visitor chooses the intelligence and grants bounded authority.

Local execution is not new. The proposed distinction is separating the agent publisher from the provider of its intelligence, memory and execution resources.

04 / DESIGN PRINCIPLES

Openness depends on the boundaries.

01

Independent choice

Any conforming Studio, Hosting service and Surfer should be interchangeable.

02

Cheap publishing

Serving a package is distinct from paying for inference. Compute happens where an agent is run.

03

Visitor control

Choose local or remote models, memory, tools and execution limits.

04

Verified, not blindly trusted

Signatures verify provenance, not safety. Sandboxing and capability grants remain essential.

05

Open discovery

Agents can be resolved and discovered across independent registries and naming systems.

06

Composable agents

Agents and skills can be reused and combined without requiring a single vendor's stack.
