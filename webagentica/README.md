# WebAgentica — GitHub Pages single-page site

A static, responsive, one-page website presenting the **WebAgentica** proposal: an open web for independently created, hosted, and executed portable AI agents.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `webagentica`).
2. Upload all files and folders from this directory to the **repository root** (not a nested directory).
3. In GitHub go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. GitHub will provide a URL such as `https://YOUR-USERNAME.github.io/webagentica/`.
6. For a custom domain, set it in GitHub Pages settings and configure the domain's DNS as GitHub instructs. Add a `CNAME` file only after choosing the actual domain.

No build step or dependencies are required. Open `index.html` in a browser for local preview.

## Structure

- `index.html`: all website content (single page)
- `styles.css`: responsive design
- `assets/media/`: existing WebAgents demo and poster
- `assets/paper/` and `assets/talk/`: original research documents
- `assets/fonts/` and `assets/img/`: supporting design assets
